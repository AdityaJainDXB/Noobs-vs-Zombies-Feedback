# 🧟 Noobs vs Zombies — Playtest Feedback

Thanks for playtesting **Noobs vs Zombies**, a Roblox tower-defense game! This repo is where you report bugs and share ideas. The game's code is private, so all you'll find here is the issue tracker.

## How to give feedback

1. Open the **[Issues](../../issues/new/choose)** tab.
2. Pick a template:
   - 🐛 **Bug report**: something is broken or behaves wrongly
   - 💡 **Suggestion**: a new feature or an idea for improving one
   - ⚖️ **Balance feedback**: something is too strong, too weak, too expensive, or too hard
3. Fill it in. Screenshots or short clips help a lot!

## Before you post

- Search the existing issues first. If someone already reported it, add a 👍 or a comment instead of opening a new one.
- Report one problem per issue.
- Be kind. Everyone here is helping make the game better.

## Useful details to include

- Your device (PC / Mac / phone / tablet / console)
- Where it happened (lobby, which map, which difficulty, which wave)
- What you expected vs. what actually happened
- Whether you can make it happen again, and how
